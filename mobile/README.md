# BOO Arcade — Native iOS / Android wrapper

Phase 1 scaffold (V1_89). Wraps the existing HTML5 games from `../Games/` into a native iOS app via Capacitor 6. The web site at `bunchofothers.com` and this app share the same game source files — there is no parallel codebase.

See `/Users/kevin/.claude/plans/i-want-to-take-noble-gizmo.md` for the full plan.

## Source of truth

```
BOO-Website/
├── Games/                   ← CANONICAL game files (edit these)
├── Images/                  ← shared image assets
├── Music/                   ← shared audio assets
└── mobile/
    ├── build-www.sh         ← copies Games/Images/Music → www/
    ├── www/
    │   ├── index.html       ← arcade menu shell (authored)
    │   ├── menu.css         ← (authored)
    │   ├── menu.js          ← (authored)
    │   ├── Games/           ← BUILD OUTPUT (gitignored)
    │   ├── Images/          ← BUILD OUTPUT (gitignored)
    │   └── Music/           ← BUILD OUTPUT (gitignored)
    └── ios/                 ← Xcode project (committed)
```

The only authored files inside `www/` are the menu shell. Everything else is regenerated by `build-www.sh`. You can safely `rm -rf www/Games www/Images www/Music` — `npm run build` rebuilds them from the canonical sources.

## Quick start

```bash
cd mobile
npm install                    # one-time: install Capacitor + plugins
npm run build                  # sync ../Games, ../Images, ../Music into www/
npx cap sync ios               # copy www/ into the iOS bundle
npx cap open ios               # open Xcode (if installed)
```

`npm run ios` is a shortcut for the build + sync + open chain.

## Prerequisites

| Tool | Version | Install |
|---|---|---|
| Node.js | 20+ | nodejs.org or `brew install node` |
| Xcode | 15+ | App Store |
| **CocoaPods** | latest | `brew install cocoapods` (REQUIRED — Capacitor warns if missing) |
| Apple Developer | $99/yr | developer.apple.com (needed for App Store submission, NOT for local testing on simulator or side-loading to your own iPhone with a free Apple ID) |

> **Heads-up:** the first `npx cap add ios` run skipped CocoaPods install because `pod` wasn't on PATH. After installing CocoaPods, run `cd ios/App && pod install` then `npx cap sync ios` again.

## Editing a game

The canonical source is `../Games/<game>.html` at the repo root. To update the iOS app after editing a game:

```bash
cd mobile
npm run build && npx cap sync ios
```

Then rebuild in Xcode.

## What's in Phase 1

- One playable game: **Neon Brickbreaker**.
- Six other games show as "Coming soon" placeholders to demonstrate the full arcade scope to Apple App Review without needing every game polished.
- Native menu shell with BOO neon identity, ambient psychedelic halos, splash veil.
- Capacitor plugins: `@capacitor/app` (back button), `@capacitor/haptics` (tap feedback), `@capacitor/share`, `@capacitor/splash-screen`, `@capacitor/status-bar`.
- Game shell: tapping Brickbreaker opens it in a fullscreen iframe overlay; X button (or Android hardware back) returns to the menu.

## Phase 2 — what changes

## App Store identity (configured in `capacitor.config.json`)

- **App ID:** `com.bunchofothers.arcade`
- **Display name:** `BOO Arcade`
- **Splash background:** `#0a0a0a` (BOO black)
- **Status bar style:** `DARK` (light icons on dark background)

Change app icon and splash via Capacitor's [iOS app icon](https://capacitorjs.com/docs/guides/splash-screens-and-icons) flow (`@capacitor/assets` package, generates all required sizes from a single source PNG).
